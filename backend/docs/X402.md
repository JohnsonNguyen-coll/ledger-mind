# x402 Live Mode

LedgerMind keeps real payment execution off by default.

```dotenv
PAYMENT_MODE=binance
REAL_PAYMENTS_ENABLED=true
BAW_CLI_JS=C:/absolute/path/to/@binance/agentic-wallet/dist/index.js
MAX_PAYMENT_USD=0.01
DAILY_BUDGET_USD=0.50
MAX_TASK_BUDGET_USD=0.01
```

## Safety Rules

- Only allowlisted merchant endpoints can be paid.
- The LLM cannot choose arbitrary payment URLs or recipients.
- Every paid request is checked against per-payment, per-task, daily, and app allowance limits.
- Private keys stay inside Binance Agentic Wallet.
- Settlement is shown only when a real merchant receipt is returned.

## Checks

```powershell
npm.cmd run setup:live
npm.cmd run check:live
npm.cmd run build
npm.cmd run start:live
```
