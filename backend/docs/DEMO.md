# LedgerMind Demo

## Local Run

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd start
```

Open `http://127.0.0.1:3000`.

## 90-Second Walkthrough

1. Open LedgerMind and show that the first screen is the treasury command center.
2. Enter a real wallet address.
3. Select Base or BNB Smart Chain.
4. Run Treasury Analysis.
5. Point to verified data sources: RPC, Blockscout, and Binance prices.
6. Explain the core metrics: treasury value, stable buffer, net flow, runway, and risk.
7. Ask LedgerMind: "What is the biggest risk?"
8. Open the workflow draft and show that it is human-approval ready.
9. Show report history, Markdown export, and the report audit trail.
10. Mention x402 as premium paid data access with spend caps and no fake receipts.

## Suggested Pitch

LedgerMind is an Agent OS treasury intelligence workflow for onchain teams. It reads real wallet activity and market prices, calculates runway and exposure risk, then drafts human-approved treasury workflows. For premium context, LedgerMind can use x402 paid data access through Binance Agentic Wallet under strict budget and audit controls.
